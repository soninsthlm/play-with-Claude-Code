# FreakinFood Sitemap

## Pages

### Homepage (`front-page.php`)
- Hero section (background image + title + CTA)
- Featured recipes grid (6 posts)
- CTA block (collaboration callout)

### Recipes + Blog (`archive.php`)
- Filter bar with recipe tags
- Content feed (3-column card grid)
- Pagination
- **Tags:** Fusion, Italian, Vietnamese, Swedish, Stories, Reviews

### Single Post (`single.php`)
- Post header (tags, title, meta)
- Featured image
- Post content (supports Gutenberg blocks)
- Post navigation (prev/next)

### Explore (`page-explore.php`)
- Restaurant cards (ACF repeater or Elementor)
- City food maps (embedded Google Maps saved recommendation lists)

### About (`page-about.php`)
- Founders' story (text + image, 2-column layout)
- Collaboration form (Contact Form 7 or fallback HTML)
- Contact info + social links

## Shared Components
- Header with sticky nav + mobile hamburger menu
- Footer with 3 widget columns
- Recipe/blog card (thumbnail, tags, title, excerpt, meta)
- Tag pills (filter navigation)
- CTA block (reusable section)
- Buttons (primary, outline, white variants)
